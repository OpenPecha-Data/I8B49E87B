## Title
	- ཤངས་པའི་རྣལ་འབྱོར་ཐེམ་སྐས་གདམས་ངག་ཕྱོགས་བསྒྲིགས།
	- དེབ་ཕྲེང་གསུམ་པ།
	- ལག་ལེན་སུམ་སྦྲེལ་གྱི་གདམས་པ། །
	- གསང་ཐིག་སྙིང་པོའི་སྐོར་ལས་རྡོ་རྗེ་གཞོན་ནུ་ཕྱག་རྒྱ་གཅིག་པའི་ལྷ་ཁྲིདརབ་གསལ་ཁྲག་འཐུང་དགྱེས་པའི་གད་རྒྱངས།
	- གསང་ཐིག་ཕུར་པའི་དམིགས་རིམ་གནད་བསྡུས་གྲུབ་གཉིས་ཐིག་ལེ།
	- གསང་ཐིག་ཡི་དམ་སྐོར་གསུམ་ལས་རྡོ་རྗེ་ཕུར་པའི་བསྐྱེད་རིམ་གྱི་ཟིན་བྲིས།
	- གཏོར་མའི་དེ་ཉིད་བདུད་རྩིའི་དགའ་སྟོན།
	- གཏོར་མའི་ཟིན་བྲིས་དབུ་ཕྱོགས་ལེགས་པོ།
	- ལུས་མཆོད་སྦྱིན་གྱི་ཟིན་བྲིས་མདོར་བསྡུས་ཀུན་དགའི་སྐྱེད་ཚལ།
	- ཐེག་པ་ཆེན་པོ་བློ་སྦྱོང་དོན་བདུན་མའི་ཁྲིད་ཡིག་བློ་དམན་འཇུག་བདེར་བཀོད་པ་བྱང་ཆུབ་གཞུང་ལམ།
	- ཐེག་པ་ཆེན་པོའི་བློ་སྦྱོང་དོན་བདུན་མའི་ཉམས་སུ་ལེན་ཚུལ་སྙིང་པོར་དྲིལ་བ་ཕན་བདེའི་ས་བོན།
	- གཅོད་ཀྱི་ཚོགས་ལས་ཡོན་ཏན་ཀུན་ལྡན་གྱི་དམིགས་རིམ་བླ་མའི་གསུང་རྒྱུན་གྱི་ཟིན་བྲིས་ཤེལ་དཀར་མེ་ལོང༌།
	- ལུས་མཆོད་སྦྱིན་གྱི་ཟིན་བྲིས་ཀུན་དགའི་སྐྱེད་ཚལ་གྱི་དམིགས་རིམ་དཔེའུ་རིས་དྲན་པའི་མེ་ལོང༌།
	- ༄༅། །ལུས་མཆོད་སྦྱིན་གྱི་ཟིན་བྲིས་ཀུན་དགའི་སྐྱེད་ཚལ་གྱི་དམིགས་རིམ་དཔེའུ་རིས་དྲན་པའི་མེ་ལོང་ཞེས་བྱ་བ་བཞུགས་སོ། །
